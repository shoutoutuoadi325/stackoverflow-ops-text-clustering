默认 SparkPi 命令在本次复核中出现较长 YARN 资源等待。改用小内存参数后成功运行：

```bash

  --driver-memory 512m \
  --executor-memory 512m \
  --executor-cores 1 \
  --num-executors 1 \
  --conf spark.dynamicAllocation.enabled=false \
  --class org.apache.spark.examples.SparkPi \
  /opt/bigdata/spark/examples/jars/spark-examples_2.12-3.5.1.jar 10
```

## 5. 现场建议

- 答辩前先执行一次 `--top-clusters` 预热 Spark/YARN。
- 如果现场时间紧，优先展示 `--top-clusters` 与 `--keyword "group by"`。
- 若要展示问题 ID 查询，使用 `28753859`，它属于最终高置信重复簇。
- 当前 worker1 偶发调度或磁盘读取较慢，现场演示时建议提前打开 YARN UI 或保留日志作为备选说明。
