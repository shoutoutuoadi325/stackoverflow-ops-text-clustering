# 最终创新点与实验结果

创新点必须同时满足三个条件：当前代码可定位、运行结果可验证、边界可以解释。最终保留以下六项。

## 创新点 1：主题聚类驱动的语义 Blocking

旧流程将 BisectingKMeans 与全局 LSH 平行运行，主题结果没有参与去重。最终流程先聚类，再在每个 topic 内独立运行 MinHashLSH，使主题聚类成为候选空间生成器。

这不是新算法发明，而是对检索流水线的结构修正：由“两个独立展示算法”变成“粗粒度语义召回 + 细粒度 Jaccard 精筛”。

证据：K=50 主题内 LSH 产生 43 对、39 簇、81 个问题；最大簇包含 4 个 ORA-00907 的不同表述。

## 创新点 2：ORA 结构化领域信号与跨主题混合图

ORA 从普通 token 迭代为 `ora_codes` 数组，并进入相似度与图结构：

1. 同主题候选共享 ORA 时加 0.10 boost，并支持 rescue floor。
2. 跨主题文档按有效 ORA 码 join。
3. 使用完整 token Jaccard 下限 0.55，或“标签有交集 + token Jaccard 不低于 0.50”控制补边质量。
4. 新边与 Baseline 去重合并后重新计算连通分量。

注意：源码参数名 `title_sim_floor` 是历史命名，实际计算的是完整 `tokens` 集合 Jaccard，不是只计算标题。

证据：K=50 从 39 簇/81 问题提升到 42 簇/87 问题；K=200 从 35 簇/72 问题提升到 40 簇/82 问题。

## 创新点 3：任务隔离式向量 Folding

`topic_clustering.py` 只对 BisectingKMeans 的训练向量做 modulo folding：

- 4x：262144 -> 65536。
- 2x：262144 -> 131072。
- MinHashLSH 始终读取未压缩的 `term_features`。

这将“主题训练资源优化”与“相似度特征质量”隔离，避免为了大 K 牺牲 LSH 表示。

证据：2x/4x 在 K=150 和 K=200 上都得到 42 对、40 簇、82 个问题；但每组只有 37/42 条 Hybrid 边重合，说明宏观稳定不等于微观完全无损。

## 创新点 4：K 与压缩的双层稳定性实验

项目不只比较计数，还比较边集合：

- 同一 4x 方案，k150 与 k200 的 42 条 Hybrid 边完全相同。
- 同一 2x 方案，k150c2 与 k200c2 的 42 条边完全相同。
- 4x 与 2x 之间共同 37 条边，集合 Jaccard 0.7872。

由此得到更严谨的结论：K=150 已达到候选结果收敛；压缩倍数不影响聚合规模，但会扰动约 11.9% 的单边，应保留样例审核。

## 创新点 5：Spark Lineage 物化截断

主题内 LSH 的多个 topic DataFrame union 后，若直接进入 15 轮连通分量，Spark lazy evaluation 会在每轮重算上游 LSH。最终代码先写 `similar_pairs` Parquet，再从 Parquet 重读，明确切断 lineage；迭代内部继续用 `localCheckpoint`。

这是可迁移的 Spark 工程经验：已经计算完成的小边集应物化，不能让迭代算法携带昂贵的上游 DAG。

## 创新点 6：瘦候选生成与可审计证据链

MinHashLSH 内部 join 只携带 `doc_id + term_features`，候选产生后再回填 title、score、tokens、ORA 等重字段，降低 cross-join 的序列化和内存压力。

结果层不提交 Raw Parquet 和完整日志，只提交 summary、样例边、救援记录、簇样例和对比表。每条边保留 `similarity_raw`、`shared_ora_codes`、`ora_rescued`、`cross_topic`、`edge_source`，便于答辩和复核。

## 不作为最终创新点的内容

- 标签分块 LSH：有代码但没有纳入最终六组结果。
- 主题拆分 `split_topic_clusters.py`：保留为大 K 备用路径，但最终六组使用的是向量 folding。
- 静态 Demo：是交付方式，不是算法创新。
- LLM-as-a-Judge：标签缺少逐条理由，作为评测补充，不作为核心创新。

## 答辩主结论

> 项目最主要的创新不是使用了更多算法，而是把候选生成、领域补边和 Spark 资源控制连成可复现流水线，并用边集合重叠而不只是结果数量验证稳定性。
